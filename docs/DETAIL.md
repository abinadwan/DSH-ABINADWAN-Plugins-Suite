# ABINADWAN Plugins Suite

**Experimental open-source package** · v0.4.0

A modular toolkit for DeepSeek Harness. Includes **one working plugin** and two planned modules:

## Available now: Environment & Context
A read-only right-side session inspector for workspace context, context pressure, output-token summaries and recent activity. Missing Connectors/Git data is labeled unavailable rather than fabricated.

## Planned: Humanizer
Natural-writing and tone controls. Not implemented or enabled.

## Design pending: Personal Profile
Opt-in user instructions and optional personal information. Personal information would only be retrieved when relevant and permitted. No profile fields or data storage exist yet.

## Versions
The suite's Plugins detail page offers **Check for updates**, a manual comparison against the public GitHub main branch. No automatic installs.

## Install

```powershell
dsh plugin --profile desktop add github:abinadwan/DSH-ABINADWAN-Plugins-Suite
```

Restart Harness and open a conversation to view Environment & Context.
