# Personal Profile — 0.7.1 candidate

Optional preferred name, nationality, gender, structured style preferences and custom instructions. Native Harness settings, explicit Save, revision-checked edits and manual JSON export/restore. No plugin-level encryption, no model disclosure or agent instruction injection. Disabled by default. See [design and acceptance](../../docs/PERSONAL_PROFILE_LOCAL_SETTINGS.md). The Phase 1–6 encrypted-storage designs are historical; not current implementation.
