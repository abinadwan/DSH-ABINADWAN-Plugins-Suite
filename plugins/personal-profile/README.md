# Personal Profile

**Status: Design pending — NOT implemented or installed in v0.4.0.**

The preliminary behavior decision is:

> Apply approved style instructions automatically; retrieve optional personal information only when it is relevant to a user request and permitted by the user.

The field list and final interface are **deliberately not decided yet**. The user will review them in a later discussion.

Privacy requirements to resolve before coding:

- Voluntary fields, including user-defined custom fields.
- Per-field access and explicit permission boundaries.
- Local storage, encryption, account isolation and export/deletion policy.
- Clear separation of instructions from personal data so personal records are not copied into every prompt.
- No upload of profile records to GitHub or any plugin telemetry service.

**This version stores zero Personal Profile information.**
